# 오르카 전기 (프로토타입)

라스트오리진 에셋으로 만든 **랑그릿사식 전술 시뮬레이션 RPG**. 빌드 과정 없는 HTML/CSS/JS이며,
지도와 전투 연출은 three.js(r128, `js/vendor`)로, 캐릭터는 5_LAO_Defence의 SD 리그 재생기(`js/sd.js`)로
원작 Unity 프리팹·클립을 그대로 재생합니다. 모바일 세로·가로, PC 모두 지원합니다.

## 실행

`게임 실행.bat` 더블클릭 (Python 3 필요) 또는

```
python tools/serve.py 8795
```
→ http://localhost:8795

## 게임 방식

- **지휘관과 용병**: 영웅(★)은 용병 부대를 거느린다. 용병은 지휘관의 지휘 범위(노란 테두리) 안에서 공격·방어 보정을 받고,
  지휘관이 쓰러지면 함께 퇴각한다. 지휘관 바로 옆의 용병은 차례 시작 시 병력 +2.
- **병력 10**: 모든 부대의 병력은 10. 남은 병력이 곧 싸우는 병사 수 — 전투 연출에서도 그만큼의 SD가 늘어선다.
- **병종 상성**: 경장 ▶ 중장 ▶ 기동 ▶ 경장, 기동 ▶ 사격, 비행 ▶ 지상 근접, 사격 ▶ 비행. 우위 x1.25 / 열세 x0.85 (공방 모두).
- **사격**: 사거리 2. 두 칸에서 쏘면 근접 부대는 반격하지 못한다. 붙어서 싸우면 약해진다.
- **지형**: 숲·언덕·산·마을·요새는 방어 보정, 마을·요새에서 차례를 시작하면 병력 +3. 적과 맞닿은 칸에 들어가면 멈춘다(지배 영역).
- **특기**: 지휘관마다 MP로 쓰는 특기(범위 화염, 회복, 강화, 직선 레이저 등). 차례마다 MP +1.
- **성장**: 경험치 100마다 레벨업, Lv5·Lv10에서 전투가 끝날 때 **전직**(능력치·지휘 범위·용병 수·새 특기).
- **출격 준비**: 전투마다 자금으로 용병을 고용한다(지휘관마다 고를 수 있는 병종이 다름).
- **자동 전투**: 상단 「자동」을 켜면 아군도 판단 장치가 움직인다.
- 진행 상황은 브라우저 저장소에 저장된다.

## 조작

| 입력 | 동작 |
|---|---|
| 누르기 / 클릭 | 선택 · 이동 · 공격 (빨간 범위의 적을 누르면 알맞은 칸으로 다가가 공격) |
| 끌기 / 두 손가락 / 휠 | 지도 이동 · 확대 |
| 오른쪽 클릭 · Esc · X | 취소 (아무것도 선택하지 않았을 때 Esc는 메뉴) |
| 방향키 + Enter | 커서 이동 · 결정 |
| E / D / Q | 턴 종료 / 적 위험 범위 / 자동 전투 |

## 구성

| 파일 | 내용 |
|---|---|
| `js/data.js` | 지형, 상성, 특기, 영웅(전직 3단계), 용병·철충, 적 지휘관, 스테이지 5개(지도·배치·이벤트·대사) |
| `js/rules.js` | 이동 범위(지형·지배 영역), 지휘 범위, 전투 계산, 특기, 경험치, 승패, 적 판단 — 화면과 무관 (node에서도 실행) |
| `js/game.js` | 지도 3D 판(캔버스로 그린 지형 + 나무·산·집 빌보드), 유닛 표시, 입력, 차례 진행, 화면들 |
| `js/battle.js` | 전투 연출: 옆모습으로 양 부대가 맞붙는 장면 (원작 공격 클립의 타격 시점에 맞춰 쓰러짐) |
| `js/sd.js`, `js/sd/*` | SD 리그 재생기와 변환된 리그 22종 (5_LAO_Defence에서 복사) |
| `js/assets.js`, `js/anim_events.js` | 초상화·이펙트 그림, 공격 타격 시점 (`tools/extract_assets.py`로 Defence에서 추출) |
| `assets/bg`, `assets/face` | 전투 배경(지형별), 대화용 표정 얼굴 (원본 텍스처에서 변환) |
| `tools/sim.js` | `node tools/sim.js`: 지도·배치 검사와 대표 전투 예상치 |

## 캐릭터 추가

리그는 5_LAO_Defence의 `js/sd/<id>.*`를 복사해 쓴다. 새 캐릭터는 Defence에서 `lao-sd-character` 절차로 리그를 만든 뒤
`js/sd/`에 복사하고, `tools/extract_assets.py`의 `RIGS`·`ICONS`에 추가해 다시 실행한 다음 `js/data.js`에 등록한다.

## 시험

창이 숨겨져 화면 갱신이 멈춘 상태에서도 시험할 수 있게, 게임 안의 모든 기다림은 화면 갱신 시계를 따른다.
콘솔에서 `GAME.run(초)`로 시간을 진행하고 `GAME.shot('이름')`으로 한 장 찍어 `tools/lab/out/`에 저장한 뒤
`python tools/shot.py 이름`으로 그림 파일을 얻는다.
