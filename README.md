# 오르카 전기 (프로토타입)

라스트오리진 에셋과 **본작 메인 스토리**로 만든 **랑그릿사 모바일식 전술 시뮬레이션 RPG**. 빌드 과정 없는 HTML/CSS/JS이며,
지도와 전투 연출은 three.js(r128, `js/vendor`)로, 캐릭터는 5_LAO_Defence의 SD 리그 재생기(`js/sd.js`)로
원작 Unity 프리팹·클립을 그대로 재생합니다. 가로 화면(PC, 1280×720 기준)에 맞춰 만듭니다.

현재 수록: **1~7지역 56개 작전** (본작 대본·선택지·배경·컷 그림·적 편성 그대로). 8지역부터는 준비 중. 7지역은 곁가지 의뢰와 전투 중 사건 대사가 아직 없다.

## 실행

`게임 실행.bat` 더블클릭 (Python 3 필요) 또는

```
python tools/serve.py 8795
```
→ http://localhost:8795

## 게임 방식 (랑그릿사 모바일식)

랑그릿사 모바일의 전투 규칙을 뼈대로 하고 라스트오리진 캐릭터·스토리를 입혔다. 규칙 근거는 운영사 공식 전투 규칙 글, 일본 공략 위키(게임위드), 영어 팬 위키, 나무위키(영어 번역판).

- **부대 = 영웅 1 + 병사 10명**: 지도 위 한 칸에 한 부대. 공격받으면 병사가 먼저 쓰러지고, 병사가 전멸하면 영웅이 맞는다.
  영웅이 쓰러지면 부대 전체 퇴각. 병사는 남은 인원 수만큼만 공격한다. 지휘관 콘스탄챠가 쓰러지면 패배.
- **병종 (화면 이름)**: 소총병·중장병·기동병·공중병·사격병·전자전병·의무병·침투병 (+변이체·해병). 랑그릿사의 보병·창병·기병·비병·궁병·법사·승려·암살자 자리.
  영웅과 병사는 저마다 병종이 있다 (예: 콘스탄챠 사격병, 그리폰 공중병 / 브라우니 소총병, 노움 중장병, 실피드 기동병, 레프리콘 사격병, 하르페이아 공중병).
- **상성** (js/data.js 의 REL): 소총병 ▶ 중장병 ▶ 기동병 ▶ 소총병 +30%, 사격병 ▶ 공중병 +40%, 공중병 ▶ 소총병 +20%·전자전병 +30%,
  전자전병 ▶ 중장병 +30%, 침투병 ▶ 사격병·전자전병 +30%, 의무병 ▶ 변이체 +80%. 병사는 병사 병종, 영웅은 영웅 병종으로 따진다.
  아군 부대는 한 번의 교전에 병사 체력의 70%까지만 잃고(어려움 90%), 넘친 피해의 40%는 영웅이 받는다(상성이 불리해도 한 번에 무너지지 않게).
  피해 = 공격 x 상성 x 공/(공+방) x 1.1 (특기는 x 1.8), 실제 피해는 예상의 ±10% 안에서 흔들린다 (난수는 판의 씨앗·차례·유닛으로 정해져 되돌리거나 행동 순서를 바꿔도 같은 행동은 같은 결과).
- **원거리**: 사격병·전자전병은 사거리 2 이상. 두 칸에서 쏘면 근접 부대는 반격하지 못한다. 원거리 병종이 붙어서 싸우면 피해 30%.
- **이동·지배 영역**: 이동력은 영웅과 병사 중 낮은 쪽. 적과 맞닿는 칸에 들어서면 그 자리에서 멈추고(지배 영역), 적 칸은 지나갈 수 없다.
  지형 방어는 숲 +20%, 산·언덕·기지 +10%, 폐허·마을 +5% (공중병은 지형 무시).
- **병사 배속·훈련**: 출격 전에 영웅마다 병사를 고른다 (전직 단계마다 고를 수 있는 병사가 는다). 전투에서 얻은 부품으로 병종을 훈련하면
  한 단계 +8% (최대 5단계). 비용이 단계마다 오르므로(120·320·640·1100·1700) 본편 부품으로는 병종 셋쯤만 끝까지 올릴 수 있다.
- **특기**: 재사용 대기 턴 방식 (예: 콘스탄챠 긴급 수리 3턴).
- **적의 움직임 (랑그릿사식)**: 적 무리마다 지휘관이 있고 부대가 지휘관 둘레로 함께 진격한다. 무리 중 하나라도 아군과 가까워지거나 한 차례가 지나면
  무리 전체가 움직이고, 상성으로 이기는 상대를 먼저 노린다. 우두머리 호위는 우두머리 곁(4칸)을 지킨다. 본작 스테이지의 웨이브는 정해진 턴의 증원으로 옮겼다.
- **난이도** (작전 도중에도 바로 적용): 옵션에서 쉬움(적 능력치 85%, 조심스럽고 늦게 움직임)·보통(111%, 배우는 1장 ×0.93, 사수 작전 ×0.95)·어려움(120%, 처음부터 진격하고 격파를 노림, 아군 정비·지휘관 곁 보충 60%, 추가 목표 턴 여유 없음). 장마다 배율이 더해진다(1장 95%·2장 100%·3장 103%·4장 105%·5장 107%·6장 108%, js/rules.js 의 R.CH_K). 어려움은 배우는 1장(×0.9)과, 적이 지킬 칸으로 몰려드는 사수 작전(×0.92)을 덜어 준다.
- **추가 목표** (본편 작전): 정한 턴 안에 승리(마지막 증원 턴 + 6턴, 쉬움 +2·보통 +1턴, 남은 턴이 2 이하면 위쪽 줄에 붉게) 또는 버티기·사수 작전은 버티며 적 60% 이상 격파 · 영웅 퇴각 없이 승리. 작전 도중 난이도를 낮춘 판은 추가 목표를 세지 않는다. 달성할 때마다 부품 +25%, 작전 정보에 ★로 남고 전투 중 위쪽 줄에 남은 턴과 함께 보인다. 놓친 목표는 깬 작전의 「본편 다시 하기」(부품 60%)로 다시 노린다. 옵션 창에는 지금 작전의 실제 배율이 나온다.
  같은 작전에서 두 번 지면 출격 준비에서 난이도를 한 단계 낮출지 묻는다.
- **전투 장면 (랑그릿사 2 원작 코드 기준)**: 소총병·중장병은 1:1 밀치기, 기동병은 적 대열을 꿰뚫고 돌아오기, 공중병은 여러 번 오가며 꿰뚫기, 사격병은 제자리 포물선 사격.
- **성장**: 전투가 끝나면 참가 영웅 전원이 같은 경험치를 받고 가장 많이 친 영웅(MVP)은 20%를 더 받는다. 출격한 영웅 중 가장 높은 레벨보다 5 이상 낮은 영웅은 따라잡기로 50%를 더 받는다(패배 시 절반, 적보다 레벨이 높으면 줄어든다). 경험치 100마다 레벨업, Lv5에 두 갈래 중 하나로, Lv10에 상위 직업으로 전직.
- **이동 경고**: 영웅을 옮길 칸에 커서를 올렸을 때 적 3기 이상(지휘관은 2기, 체력 절반 이하 영웅은 1기 이상)의 공격이 닿는 자리면 위쪽 안내 줄이 붉게 바뀌어 알려 준다.
- **★ 모으기**: 어려움에서 이룬 ★는 붉은 ✦로 따로 남고, 어려움은 추가 목표마다 부품이 +35%(다른 난이도 +25%)다. 본편 추가 목표 ★는 월드맵 아래에 모은 수가 나오고, 10개를 넘길 때마다 부품 보상(50 + 5×개수, 다 모으면 모두 3,850)을 한 번씩 받는다. 월드맵 작전 표시에는 그 작전에서 모은 ★가 붙는다. 6장을 모두 마치면 「1부 완결」 화면에 그동안의 기록이 나오고, 월드맵 「1부 기록」으로 다시 볼 수 있다.
- **작전 전술**: 출격 준비에서 작전마다 하나 고른다 — 돌격 명령(처음 3턴 공격 +22%, 방어 -15%)·방어 진형(처음 4턴 방어 +25%, 버티기·사수 작전은 작전 내내 방어 +18%·공격 +10%)·신속 전개(처음 3턴 이동 +1, 방어 -8%)·없음. 작전마다 따로 기억하고, 작전 종류에 맞는 것을 「추천」으로 표시해 처음엔 그것이 골라져 있다. 추천(작전에 맞는) 전술은 좋은 효과가 1.3배, 대가는 2/3쯤으로 덜하고 한 턴 일찍 끝난다. 출격한 아군 영웅·병사 전원에 걸리고(도중 합류는 빠짐), 걸린 동안 위쪽 줄에 표시된다.
- **각성**: 영웅이 Lv20에 이르면 부대 현황에서 하나를 고른다 — 공세(공격 +15%)·수비(방어 +25%, 체력 +6%)·생존(체력 +18%)·기동(영웅·병사 이동 +1). Lv40에는 첫째와 다른 둘째 각성을 하나 더 고른다 (꾸준히 출격하면 보통 2장 중반·3장 끝 무렵에 열린다). 영웅과 그 병사에 (병사에는 한 번만) 걸리고, 출격 준비·부대 현황에서 언제든 바꿀 수 있다.
- **자동 전투**: 상단 「자동」(Q). 도달 작전은 목표 칸으로, 사수 작전은 지킬 칸을 막아선다.
- **저장**: 진행은 브라우저 저장소에 저장된다. 작전 도중에도 행동이 끝날 때마다 저장돼 타이틀의 「작전 이어하기」로 그 자리부터 돌아온다 (작전을 포기하면 지운다). 이번 차례 안에서는 U·메뉴로 한 수씩 되돌리거나 「이번 차례 다시」로 차례 처음으로 돌아간다 (차례가 바뀌면 되돌리기는 비워진다).

- 전투 지도 바닥 질감·소품: `python tools/build_tiles.py` → `assets/tiles` (원작 전투 배경 손그림에서 이음매 없는 질감과 소품을 오려 냄)
- 전투 효과: `python tools/unity_ref/setup_fx.py` → 유니티 `-executeMethod RefFxBake.Run` (그래픽 켠 채로) → `python tools/build_fx.py` (원작 효과 프리팹을 검은·흰 바탕에 두 번 그려 미리 곱한 색의 낱장 묶음으로)
- 피해 숫자 글꼴: `python tools/build_dmgfont.py` (원작 BMFont → `assets/ui/dmg_*.png` + `js/dmgfont.js`)
- 지역 지도(3D): `python tools/unity_ref/setup_worldmap.py` → 유니티 `-executeMethod RefWorldMap3D.Run` (그래픽 켠 채로, `-nographics` 없이) → `python tools/build_world3d.py`
  (모델·재질 값·그림, 작전 지점 3D 자리, 애니메이터 상태 S_08~S_15 = 작전 1~8 카메라 클립, S_Default = 전체 둘러보기. 마을 자리는 `tools/world_old_ch01.json`의 옛 사진 위 자리를 3D로 옮김)
- 움직이는 대화 일러스트: `python tools/unity_ref/setup.py portraits` → 유니티 `RefMesh.Run` → `python tools/build_sd.py portraits` → `js/sd/p_<영웅>.*`
  (원작 2DModel 프리팹 + 로비 움직임 + 원작 표정 그림 + 원작 흔들림 뼈 설정. `js/portrait.js` 가 대화·출격 준비·결과 화면에서 재생,
  흔들림 뼈 계산은 `js/sd.js` 의 runDyn. 불러오는 동안은 정지 그림)
- 대화 전신 그림·컷 그림: `tools/unity_ref/setup_portrait.py` → `RefPortrait.Run` (컷 그림은 프리팹 안 좌우 반전을 되돌림)
- 배경음·효과음·타이틀 콜·인물 음성(합류·출격 선택·편성·작전 개시·최우수·퇴각)·글꼴: `python tools/build_media.py`

## 캐릭터 추가 (SD 리그)

변환 도구를 이 프로젝트로 옮겨 두었다 (`tools/build_sd.py`, `tools/unity_ref/`). `UNITS` / `ENEMIES`에 추가한 뒤:

```
python tools/unity_ref/setup.py <id> ...
cp tools/unity_ref/Mesh.cs tools/unity_ref/proj/Assets/Editor/RefMesh.cs
"C:/Program Files/Unity/Hub/Editor/6000.0.58f2/Editor/Unity.exe" -batchmode -nographics -quit -projectPath <절대경로>/tools/unity_ref/proj -executeMethod RefMesh.Run -logFile <절대경로>/tools/unity_ref/mesh.log
python tools/build_sd.py <id>
python tools/build_events.py
```

확인: `sdlab.html?ids=<id>` (깨진 부위 수 표시). 유니티 참조 프로젝트(`tools/unity_ref/proj`)는 저장소에 넣지 않는다.

## 시험

`node tools/sim.js`: 지도·배치 검사와 대표 전투 예상치.
창이 숨겨져 화면 갱신이 멈춘 상태에서도 시험할 수 있게, 게임 안의 모든 기다림은 화면 갱신 시계를 따른다.
콘솔에서 `GAME.run(초)`로 시간을 진행하고 `GAME.shot('이름')`으로 한 장 찍어 `tools/lab/out/`에 저장한 뒤
`python tools/shot.py 이름`으로 그림 파일을 얻는다.
